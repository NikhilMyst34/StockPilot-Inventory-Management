# Project Synopsis
## Inventory Stock Management System Using Data Structures and Algorithms
**Stack:** Python, Flask, SQLite, HTML, CSS, JavaScript, C++17.
### Abstract
This web application maintains product details, tracks stock inward/outward, reports low-stock items, and stores transaction history in SQLite. DSA demonstrations include search, sorting, a FIFO queue, a LIFO stack, and hash-based SKU lookup.
### Objectives
- Centralize product records and stock levels.
- Validate stock movement.
- Flag low-stock items.
- Demonstrate searching, sorting, queues, stacks, and hashing.
### Scope
Local academic demo, seeded user/data, not production deployment.
