# User Manual
1. Extract ZIP and open terminal in project folder.
2. Run commands in README.md.
3. Open http://127.0.0.1:5000 and sign in with admin / admin123.
4. Use Products to search/add/delete, Stock Inward/Outward to update quantity, Low Stock for reorder alerts, Reports for transaction history.
Troubleshooting: install Python 3.10+, activate .venv, run pip install -r requirements.txt. To reset demo data, stop server and delete instance/inventory.db. Do not expose the Flask development server publicly.
